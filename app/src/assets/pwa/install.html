GoDirect sur votre téléphone

Retrouvez votre espace depuis l’écran d’accueil.

iPhone, dans Safari : ouvrez le menu de partage puis choisissez « Sur l’écran d’accueil ». Activez « Ouvrir comme app » si cette option apparaît.

Sur Mac, dans Chrome : cliquez sur « Install » à droite de la barre d’adresse, puis confirmez.

Android, dans Chrome : utilisez le bouton d’installation ou le menu ⋮ puis « Installer l’application » ou « Ajouter à l’écran d’accueil ».
